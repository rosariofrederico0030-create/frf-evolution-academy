# Fortaleza Rosário Frederico Evolution Academy — V5 PWA

Base instalável da plataforma digital de Inglês e Francês.

## Incluído
- Landing page
- Perfil de aluno local
- Cursos Inglês/Francês
- Níveis A1–C2
- Diagnóstico demonstrativo
- Aula interativa
- Evolution Points
- Progresso e sequência
- Área do fundador (demonstração)
- PWA: manifest + service worker + botão de instalação

## Importante
Esta versão usa `localStorage`, portanto não é ainda uma plataforma multiutilizador real. Para produção são necessários autenticação, base de dados, regras de acesso, backups, políticas de privacidade e um painel administrativo seguro.

## Publicação
Pode ser publicada como site/PWA através de um serviço de hospedagem compatível com sites estáticos. Depois, o mesmo endereço pode ser enviado aos alunos.
